# Task 1: Build a Collapsible Sidebar

A modern, responsive web dashboard component featuring a smooth collapsible sidebar, built using core web technologies. Developed as part of the Elevvo Frontend Web Development Track.

---

## 📌 Project Overview
This project implements an interactive sidebar navigation system that can seamlessly open and close via a toggle button. It emphasizes clean layout structure, smooth UI transitions, and responsiveness on mobile screens.

---

## ✨ Key Features
* **Interactive Toggle Logic:** Smooth open and close mechanism controlled via JavaScript.
* **Branding Area:** Dedicated placeholder for a company or project logo at the top.
* **Navigation Menu:** A clean list of 4–5 links equipped with visual icons.
* **Smooth Animations:** Optimized CSS transitions for a fluid user experience.
* **Fully Responsive:** Adapts seamlessly across different screen sizes, including mobile devices.

---

## 🛠️ Tech Stack & Tools
* **HTML5:** Semantic markup structure.
* **CSS3:** Flexbox layout, styling, and transition animations.
* **JavaScript (ES6):** DOM manipulation and event handling for the toggle functionality.
